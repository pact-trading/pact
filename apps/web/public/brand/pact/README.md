# Pact Soft Gate brand kit

This kit contains the selected Rounded-Square Core identity.

## Meaning

Four equal voices gather around one shared treasury and policy core. The four-way symmetry communicates balanced authority, conversation, voting, and collective governance.

**Brand line:** Four voices. One treasury. One pact.

## Palette

- Obsidian: `#0B0D0E`
- Warm white: `#F4F2EC`

## Contents

- `svg/`: standalone mark, horizontal lockup, light variants, and app icon
- `png/`: transparent raster exports
- `favicon/`: browser and app-icon sizes

All logo artwork is built from vector paths and does not require an installed font. Keep clear space around the mark equal to at least one quarter of its width. Do not stretch, rotate, add effects, or recolor individual modules.
